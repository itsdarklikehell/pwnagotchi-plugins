### Veelgestelde vragen

**Q: Hoe installeer ik een plugin?**
A: Kopieer het `.py` bestand naar `/usr/local/share/pwnagotchi/available-plugins/` en activeer het met `sudo pwnagotchi plugins enable <naam>`.

**Q: Hoe test ik een plugin?**
A: Voer `pytest tests/` uit in de repository root.

**Q: Hoe rapporteer ik een bug?**
A: Maak een GitHub Issue aan met de bug_report template.

**Q: Hoe stel ik een plugin voor?**
A: Maak een GitHub Issue aan met de feature_request template.

### Systemvereisten
