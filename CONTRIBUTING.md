# Contributing to pwnagotchi-plugins

Bedankt voor je interesse om bij te dragen aan deze Pwnagotchi plugin-collectie!

## Hoe bij te dragen

1. **Fork** de repository
2. **Creëer** een nieuwe branch (`git checkout -b feature/my-plugin`)
3. **Voeg** je plugin toe of bestaande plugin te verbeteren
4. **Test** je plugin lokaal op een Pwnagotchi of in een testomgeving
5. **Commit** je wijzigingen met duidelijke commit messages
6. **Push** naar je fork
7. **Open** een Pull Request

## Plugin-richtlijnen

- Plugins moeten Python 3.7+ compatibel zijn
- Gebruik het `plugins.Plugin` base class
- Voeg een `.toml` configuratiebestand toe in `configs/`
- Documenteer je plugin in de README.md tabel
- Test je plugin voordat je het indient

## Code-stijl

- Volg PEP 8 voor Python-code
- Gebruik duidelijke variabelenamen
- Voeg comments toe waar nodig
- Houd plugins kort en gefocust

## Rapporteren van bugs

Gebruik GitHub Issues om bugs te rapporteren. Voeg toe:
- Pwnagotchi versie
- Plugin naam
- Stappen om te reproduceren
- Verwacht vs. werkelijk gedrag
