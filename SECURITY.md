# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| latest  | :white_check_mark: |

## Reporting a Vulnerability

Als je een veiligheidslek vindt in een van de plugins, volg dan deze stappen:

1. **Maak geen public issue aan** voor het lek
2. **Stuur een email** naar de onderhouder met details
3. **Beschrijf** het lek duidelijk:
   - Welke plugin is betrokken
   - Hoe te reproduceren
   - Mogelijke impact
   - Suggestie voor fix (optioneel)

We streven naar:
- Binnen 48 uur te reageren op het rapport
- Binnen 2 weken een fix te publiceren (indien nodig)
- Je te informeren over de voortgang

## Scope

Dit project bevat Pwnagotchi plugins voor educatieve en pentest-doeleinden.
Veiligheidsproblemen in plugins die leiden tot:
- Remote code execution
- Privilege escalation
- Data exfiltration
- Ongeautoriseerde netwerktoegang

Zijn in scope.

## Disclaimer

Dit project is bedoeld voor **legitieme security research en educatieve doeleinden**.
Gebruik alleen op apparaten en netwerken waar je toestemming voor hebt.
